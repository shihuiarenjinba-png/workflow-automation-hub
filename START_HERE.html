Workflow Automation Hub — はじめに

利用者が指定した決定論的ルールでBloggerの内部リンク更新を行うローカル優先ツールです。v0.1のproduction connectorはBloggerのみです。

最初にやること

  1. EXEを起動し、Google Desktop OAuth JSONをインポートします。
  2. Googleへ接続し、Blogger Connection Testを実行します。
  3. 対象Blog、検索文字、リンク文字、リンクURL等を設定します。
  4. 必ずDry Runで対象と変更候補を確認します。
  5. 承認した場合だけcontrolled live updateを実行し、backupとaudit logを確認します。

入力例

Blog内の「製品一覧」という最初の通常テキストへ、許可したURLを1回だけ挿入。同じURLが既にあれば変更しません。

出力されるもの

設定、jobs、暗号化credential、audit log、Blogger backupは%LOCALAPPDATA%\WorkflowAutomationHubへ保存します。OAuth JSON／tokenを配布ZIPやGitHubへ入れません。

よくあるエラー

Web application用OAuth JSON、外部redirect、Blogger未許可、backup失敗、重複実行、移動後の古いSchedulerパスを確認します。backup失敗時はlive updateしません。

対応環境・既知の制限

任意API／任意コマンドの自動化ツールではありません。初版SchedulerはWindowsログオン中だけ動作します。実Google OAuth/API acceptanceとレビュー完了まで販売HOLDです。
